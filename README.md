# 2026 上海出发家庭旅行可视化地图

这是一个静态网页地图，用来展示 2026 年 7 月下旬从上海出发，经过洛阳、太行山、山西古建、《黑神话：悟空》相关取景点、阿尔山大兴安岭的家庭旅行方案。

## 内容

- 21 天混合交通行程
- 24 天全程自驾行程
- 高铁、自驾、飞机路线分层
- 景点、住宿基地、美食点弹窗
- 每日车程、门票、住宿、饮食和预算区间

## 本地浏览

```bash
python3 -m http.server 5173
```

然后打开：

```text
http://localhost:5173
```

## 说明

门票、航班、车票、酒店和租车价格都会随暑期客流变化。页面中的价格是行程规划区间，正式出发前请以 12306、航司、景区公众号、租车平台和酒店平台为准。
